# Archived scripts

The 78 modules under `passthru_data/`, the former top-level pass-through runner, and the historical benchmark contract are preserved as development history. Their current replacements are:

- `scr/data_construction/` for Census and tariff construction;
- `scr/pass_through/` for the locked regressions and figures;
- `master_pipeline.py` for orchestration.

Archived modules may contain intentionally incomplete diagnostics and must not be used as release entry points.
