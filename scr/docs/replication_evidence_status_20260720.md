# Replication evidence status — 2026-07-20

The reproducible historical estimator is separately identified from the
independent policy experiment. The package-only import benchmark uses the
authors' `m_flow_hs10_fm_new.dta` fields and passes the frozen local PDF gate:
eight fits, 13 horizons per fit, and maximum absolute difference `0.86862`.
The raw-outcome bridge uses the same normalized package-common keys and passes
all registered point-estimate criteria. Its only remaining registered failure
is the event duty-inclusive confidence-interval overlap diagnostic.

The independent pooled policy build is not yet locked. It constructs Section
201/232/301 actions from local HTS/Chapter-99 sources. A chunked DTA projection
containing `m_increase`, `m_stattariff1/2`, dates, and family-hit flags is used
only as a labeled validation anchor. The pooled comparison has 4,199,002
common rows, treatment match `0.986741`, trade-weighted treatment match
`0.975572`, additional-rate MAE `0.029182`, and exact legal-month match
`0.432395` against package `m_effective_mdate1`. These results are diagnostic and do not authorize a pooled policy
lock or Section 301 v5 estimation.

The independent raw-trade extension covers all local import and export ZIP
months from 2013-01 through 2025-12 in ZSTD Parquet. Archive-native validation,
quantity-token semantics, duty-field preservation, native concordance changes,
and CPI-real fields are distinct gates. Nominal trade values remain canonical;
CPI files remain preserved for future work but are not required for nominal
Figures 2 or 4a. No 2025 policy/event regression is estimated.
